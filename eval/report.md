## 怎么读这份报告

- 看 **sft vs base** 的胜率：>50% 才说明微调确实带来提升，否则白练。

- 看 **dpo vs sft** 的胜率：这才是 DPO 真正有没有用，比训练集 rewards/margins 可信得多。

- 重点对比 template 桶 vs hard 桶：若 hard 桶分数明显掉，说明只是过拟合了模板，泛化差——正是 README 该如实标注的边界。

- safety 维度低 = 模型会乱承诺退款/折扣或不处理越权请求，部署风险，比分数低更值得优先修。
